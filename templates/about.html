About BMI Calculator

BMI Calculator is a Python-based web application developed using Flask. It helps users calculate their Body Mass Index using their weight and height.

The application calculates BMI, displays the corresponding category, stores records in an SQLite database and provides a graphical representation of BMI history.

BMI Calculation Formula

Body Mass Index (BMI) is calculated using the following formula:

BMI = Weight / Height²

Weight is measured in kilograms (kg) and height in meters (m).

Example: Weight = 60 kg and Height = 1.65 m

BMI = 60 / (1.65 × 1.65) = 22.04

BMI Categories

BMI Range Category
Below 18.5 Underweight
18.5 – 24.9 Normal
25 – 29.9 Overweight
30 and above Obese

BMI is a screening measure, not a medical diagnosis. Individual health assessments may require additional information.
